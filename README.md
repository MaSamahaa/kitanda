# 🛒 Kitanda

**Kitanda** é um aplicativo mobile desenvolvido em Flutter com foco em praticidade e experiência agradável para usuários que desejam comprar produtos como orgânicos, carnes, pães e muito mais — direto do celular.

## 📱 Funcionalidades

- Autenticação com email e senha
- Animações suaves com [animated_text_kit](https://pub.dev/packages/animated_text_kit)
- Campos de texto personalizados com ícones e visibilidade de senha
- Layout moderno com cores personalizadas
- Interface responsiva e adaptada para diferentes tamanhos de tela

## 🎨 Tecnologias

- [Flutter](https://flutter.dev)
- [Dart](https://dart.dev)
- [animated_text_kit](https://pub.dev/packages/animated_text_kit)
